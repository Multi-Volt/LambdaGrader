How it works

  1. Students: import or type your roster of name.# IDs (up to 400).
  2. Answer key: type the key as plain text, e.g. 1. B, or 2. ACD for select all that apply.
  3. Bubble sheets: print blank sheets, or personalised sheets with each student's name and name.# pre-filled.
  4. Scan & grade: scan the completed sheets to a PDF (150 dpi or better) and drop it in.
  5. Results: review flagged sheets, then download the CSV.

🔒 Everything (roster, keys, scans, scores) stays on this computer, in this browser. No data is uploaded anywhere. Use Backup to move your data to another browser.

Import

Paste from a spreadsheet or load a CSV. Columns: name.#, name, section. A header row with name.# (or username, email, id), name (or first / last) and section is recognised. Emails like smith.12@school.edu are trimmed to smith.12.

Numbers after the dot can repeat (smith.12 and jones.12). Personalised sheets carry a hidden code that always matches the exact student. On blank sheets you pick between students who share a number when reviewing.

Tools

The roster is shared by all exams. After printing personalised sheets, edit students rather than deleting and re-adding them, so their printed code still matches.

Answer key

Key format 
1. A            one correct answer
2) c            case and punctuation don't matter
3 B 2           worth 2 points (default 1)
4 A/C           either A or C is accepted (A,C works too)
5 ACD           select all that apply: A, C and D must all be marked
6 A+C 2 partial select all, 2 points, partial credit
7 BD exact      select all, all or nothing
8 *             free: everyone gets credit
9 -             dropped: not scored
# comments start with a hash

ABCDA DCBAB     or just letters in order;
[ACD] B [A/C]   [..] groups, * and - work here too

Partial credit for select-all questions is set on the Exam tab (or per question with partial / exact). Enter the key before scanning so extra marks on select-all questions aren't treated as mistakes. If you add it later, use "Re-read this session's sheets".

Printing tips

  • Print at 100% or "fit to page". Both work; the corner squares handle scaling.
  • Don't change the exam settings after printing. The sheet records its own layout in the small squares along the top edge, so mismatches are detected.
  • Single-sided only. Scan in grayscale or colour; 200–300 dpi is ideal.
